Good to know

Before you ask.

Is it really not too late?

+

Not if you book now. Ready-made worlds and frames only need your logo and text, and custom designs can be ready within days. Rush slots are limited and go first come, first served.

How much space does it need?

+

Just a safe spot for the laptop and printer, and a normal power socket. The screen size is flexible.

Does it need Wi-Fi?

+

The AI runs locally, but stable Wi-Fi is required for the web app.

Do you need to be there?

+

Your choice: we run it on site, or you run it yourselves with our remote support. Each option is priced differently.

What if someone doesn’t like their photo?

+

You choose when to print. If you don’t like it, you can retake it as many times as you like.
